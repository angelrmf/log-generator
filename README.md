# paper-tiger

A Python-based security lab for generating synthetic SSH authentication logs, testing detection logic, and exploring attacker behavior in a realistic simulated environment.

The project is designed for hands-on learning around log analysis, intrusion detection, and basic security operations. It generates realistic `sshd` activity, including benign logins, noisy background scans, and multi-stage attack patterns that can be used to test detection rules and dashboard workflows.

## What this repository contains

- `generator/loggen.py` — creates fake SSH auth logs in Linux `syslog`/`auth.log` style.
- `detector/detect.py` — parses the generated log lines and raises alerts for brute-force and successful compromise events.
- `dashboard/app.py` — a Streamlit dashboard for generating or uploading logs, tuning rule thresholds, and visualizing activity.
- `alerts.json` — sample alert output generated by the detector.

## Features

- Synthetic SSH log generation with multiple difficulty levels
- Realistic user activity and attacker noise
- Attack patterns including:
  - fast brute force
  - slow brute force
  - password spraying
  - botnet-style activity
  - comeback attacks
  - low-and-slow campaigns
- Detection rules for:
  - failed login bursts from a single IP
  - successful login from a previously flagged IP
- Interactive dashboard for exploring alerts and trends

## Quick start

### 1) Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2) Install dependencies

The project code uses `streamlit`, `pandas`, and `altair` for the dashboard.

```bash
pip install streamlit pandas altair
```

### 3) Generate a log

```bash
python3 generator/loggen.py --difficulty hard --output auth.log
```

You can also use different difficulties such as `easy`, `intermediate`, or `hard`.

### 4) Run detection against the log

```bash
python3 detector/detect.py auth.log --threshold 10 --window 60 -o alerts.json
```

The detector implements two core rules:

- `ssh_bruteforce`: flags a source IP when the configured number of failed logins occurs within the configured time window.
- `ssh_compromise`: flags a successful login from an IP that has already been identified as brute-forcing.

### 5) Launch the dashboard

```bash
cd dashboard
streamlit run app.py
```

The dashboard lets you:

- generate a fresh synthetic log
- upload an existing `auth.log` file
- tune detection thresholds in real time
- inspect charts and alert summaries
- compare results with the hidden answer key for generated logs

## Example workflow

```bash
python3 generator/loggen.py --difficulty intermediate --seed 42 --output auth.log
python3 detector/detect.py auth.log --threshold 10 --window 60 -o alerts.json
cd dashboard && streamlit run app.py
```

## Why this exists

This project is useful for:

- practicing log parsing and incident detection
- building security exercises or training labs
- testing detection logic against realistic attack patterns
- visualizing how false positives and missed detections emerge under different thresholds

## Notes

- The generated IPs are reserved documentation ranges (`203.0.113.*`, `198.51.100.*`, `192.0.2.*`) and do not map to real systems.
- The repository is intentionally focused on SSH authentication activity, but the structure is easy to extend with other log types or detection rules.
